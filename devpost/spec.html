01 / The Problem

A beginner has an idea.
Where does it go?

New developers open a coding agent and face the same wall: a blank prompt field and no idea what to type. The idea is in their head — messy, exciting, unstructured. The agent is powerful but idle. The gap between "I want to build a thing" and "Here's my Phase 1 prompt" is where most beginners stall.

Idea Breakdown Coach bridges that gap. It transforms raw, unformatted brainstorms into a clean, structured blueprint that AI coding agents understand instantly — phased milestones, a recommended stack, and the exact first prompt to type.

Built for beginners using AI coding agents for the first time. No login. No database. No cost. Just paste and build.

05 / Technical Architecture

Built to never fail on demo day.

A dual-mode engine that tries the live Gemini API first, then falls back to smart client-side templates — so the breakdown always works, every time, even offline.

01

Dual-Mode Engine

Live Google Gemini calls when an API key is set. Automatic smart offline fallback on timeout (>10s) or rate limit. Zero demo failures guaranteed.

02

Single-Page App Router

Next.js 14+ App Router. All state lives client-side in React. Zero routing complexity, zero auth, zero database. Just the core loop.

03

Agent-Ready Formatting

Copy action outputs clean Markdown with an explicit agent instruction header, so AI coding agents execute phases without extra prompting.

04

Local Dev & Recording

Runs locally at localhost:3000 with npm run dev. Sized to record a clean 1–2 minute Devpost demo video.

06 / Design Principles

Not a toy.
A real tool.

Every decision — from the color of the textarea border to the structure of the copied Markdown — is calibrated for someone using an AI coding agent for the very first time.

Principle 01

No intimidation

A single text box, three sample chips, one button. The entire interface fits in one viewport. No menus, no settings, no accounts.

Principle 02

Never fails

The smart fallback engine means the demo recording always works. No API key? No network? Still generates a valid, useful blueprint.

Principle 03

Agent-first output

The copied blueprint is structured specifically for AI agents. Not a human summary — a machine-parseable instruction document.

Principle 04

Free everything

Free API tier. Free resources. Free to run. The only investment is the idea in your head.
